# Hosted Studio

Status: IMPLEMENTED

Phase 1 runs the shared ForgeUI Studio in hosted capability mode and returns a standalone ESP-IDF project as a ZIP. It does not build, flash, persist cloud projects, authenticate users, or enable AI.

Start a proof with `FORGEUI_RUNTIME_MODE=hosted` and `NEXT_PUBLIC_FORGEUI_RUNTIME_MODE=hosted`, then run the Studio production server. See the companion documents for boundaries and validation status.
