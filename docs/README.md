## Discovery metadata

The authoritative in-product palette, navigation, search keywords, descriptions, dimensions, capabilities, and documentation IDs are maintained in `studio/src/forgeui/widgets/ForgeUIWidgetRegistry.ts`. AI discovery is maintained in `ForgeAIComponentCatalogue.ts`. This repository contains no separate public website application, website search index, or sitemap generator. [SITEMAP.md](SITEMAP.md) is the repository documentation sitemap.

Files under `docs/history/` are archival and must not be used as current platform status.
